# Use Cases Index

## Purpose

This document lists the main use cases for the Adaptive Triathlon Coach MVP.

Each use case is documented in a separate file.

---

## Use Case Groups

The MVP use cases are organized into four functional groups:

1. Setup Flow
2. Weekly Planning Flow
3. Daily Training Log Flow
4. Weekly Review Flow
